# Laboratory instructions

This is a documentation-first laboratory; no runtime stack or confirmed connected hardware exists yet.
Read README, ROADMAP, architecture, state contract and experiment protocol before implementation.
Use ROS 2 Jazzy/Gazebo Harmonic as the proposed initial baseline; preserve separate ownership of GAIA repositories.
Do not fabricate metrics, hardware, packages or working integrations. Label REAL/SIMULATED/CALCULATED/ESTIMATED and missing data.
Keep raw logs immutable and identify clock domains. Use radians/meters/seconds and explicit channel quality.
Do not create empty technology directories. Add dependencies only for a concrete experiment.
Validate links/status now; add runtime tests with executable components. Never actuate hardware from CI.
Definition of Done: scoped change, appropriate checks, commands/results/limits, references and an updated evidence record.
